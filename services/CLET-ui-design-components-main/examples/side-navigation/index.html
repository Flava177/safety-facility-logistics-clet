Side Navigation Bar

Primary app navigation for authenticated views, grouped into labelled sections (Main / Workspace / Account) the same way the site's own sidebar is. Try the section labels, the collapse toggle, and the theme switch below. Collapse is a CSS width transition plus aria-expanded, not a full remount, so item click handlers keep working either way. The Gold theme is likely a role/directorate-specific skin (confirm with design before wiring it as, e.g., an admin theme).
