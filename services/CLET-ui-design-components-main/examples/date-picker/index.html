Date Picker

Five sub-parts composed together: Day Labels, Day Cells, Period Range shortcuts, the Date Selector field, and the assembled Date & Range Picker (368×484 single / 936×484 range). Don't hand-roll date math. This demo uses plain JS Date for illustration only; wrap a maintained library (react-day-picker, @internationalized/date) in production and re-skin it with these tokens.
