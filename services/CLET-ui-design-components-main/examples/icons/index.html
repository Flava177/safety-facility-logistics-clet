Iconography

The Figma file's "Icons" page is the complete Phosphor Icons set: 18,144 symbols across 18 categories. Don't export these one at a time; install the package and reference icons by name. The tiles below are generic placeholders (this reference doesn't have Phosphor's actual SVG paths) standing in for real Phosphor icons; swap them for the real package.

Install

npm install @phosphor-icons/react
# or, framework-agnostic:
npm install phosphor-icons

Usage (React)

import { ArrowLeft, ArrowRight, Check } from "@phosphor-icons/react";

<Button><ArrowLeft size={20} /> Back</Button>
