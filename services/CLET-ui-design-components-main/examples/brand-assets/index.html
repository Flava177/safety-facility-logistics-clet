Brand assets

Most of these are placeholders, not the real marks. Logos, seals, and directorate marks are vector illustrations whose actual paths live only in the .fig file's binary vector data, which this reference (built by parsing the file's node graph) doesn't decode, so those sections document sizing, naming, and layout only. The Adinkra Symbols section below is the exception: those are the real exported assets. Export the remaining real SVGs directly from Figma. See docs §3.6.
