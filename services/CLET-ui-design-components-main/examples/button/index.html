States

Figma's "State" variant axis (Default / Hover / Focus / Press / Disabled) is not separate markup here; it's native browser state. This is intentional: it keeps assistive tech, keyboard users, and mouse users all in sync automatically, instead of a JS-driven "state" prop that can drift out of sync with what's actually focused/pressed.
