List

A row = one Left Item (Icon+Text / Avatar+Text) + one Right Item (Text+Icon / Badge+Icon / Toggle / Radio / Checkbox / Stepper). This is one <ListItem leading trailing> component with swappable slots, reusing the actual Checkbox/Radio/Toggle/Stepper/Avatar components from their own folders instead of 8 hardcoded row types.
