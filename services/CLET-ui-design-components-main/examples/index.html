CLET Design System components

Runnable HTML/CSS reference implementation for every component in docs/design-system.md. Each page is self-contained (its own CSS + minimal vanilla JS where real interaction is needed) and imports only tokens/tokens.css plus a small shared page-chrome stylesheet. Copy a component's own folder into your project, not this index.
